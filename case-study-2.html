CASE STUDY 02

College Baseball Recruiting Automation

Designed and implemented an automated workflow that transforms incoming college baseball recruiting emails into organized player records, reducing manual data entry and creating a more consistent recruiting review process.

Project Overview

Recruiting information often arrives through email in an unstructured format. Player names, graduation years, recruiting details, video links, and profile URLs can all appear in different locations within the message.

This project demonstrates how workflow automation can capture that information, identify important recruiting data, organize it into structured records, and support a more efficient review process.

Challenge

Convert inconsistent recruiting emails into standardized, usable player information.

Solution

Build an automated Make.com workflow using Gmail, pattern matching, Google Sheets, and automated email actions.

Outcome

Created a repeatable workflow that reduces manual processing and organizes recruiting information for easier review.

Tools & Methods

Make.com Gmail Regex / Pattern Matching Google Sheets Apps Script Workflow Design Process Mapping Testing Quality Assurance Data Validation

Challenges & Problem Solving

One of the most important parts of the project was determining where automation should end and human review should begin. Automated collection can improve speed, but profile information still needs to meet business standards before being used.

Testing therefore focused not only on whether the automation worked technically, but also on whether the resulting information was useful, accurate, and consistent from an operational perspective.

The workflow was refined through testing, feedback, and iteration rather than treating automation as a one-time implementation.

Business Value

  • Reduced reliance on repetitive manual profile data entry.
  • Created a more structured and repeatable profile-building process.
  • Improved the ability to scale candidate and recruiting onboarding.
  • Added validation and QA into the automation workflow.
  • Created a stronger connection between operational requirements and the technology used to support them.

How the Automation Works

  • Gmail monitors for new recruiting emails.
  • The workflow identifies and parses relevant recruiting data.
  • Pattern matching extracts recruiting video URLs.
  • Additional parsing identifies player profile URLs.
  • Structured player information is added to Google Sheets.
  • Gmail sends an automated email response after the workflow completes the required processing.
